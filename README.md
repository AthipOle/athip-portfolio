# Athip Saenpakdee — Web Portfolio

เว็บไซต์ Portfolio สำหรับสมัครสหกิจตำแหน่ง Software Tester (QA) Intern  
รองรับภาษาไทยและอังกฤษ รวมถึงหน้าจอคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ

## วิธีเปิดใน Visual Studio Code

1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `athip-saenpakdee-portfolio` ด้วย Visual Studio Code
3. เปิด Terminal ภายใน VS Code
4. ติดตั้งแพ็กเกจ:

```bash
npm install
```

5. เปิดเว็บไซต์ในโหมดพัฒนา:

```bash
npm run dev
```

6. เปิด URL ที่แสดงใน Terminal

## คำสั่งที่ใช้บ่อย

```bash
npm run dev
npm run build
npm run lint
```

## แก้ไขข้อมูล

- เนื้อหาและลิงก์: `app/page.tsx`
- สี รูปแบบ และ Responsive layout: `app/globals.css`
- รูปภาพ: `public/portfolio`
- ชื่อและคำอธิบายเว็บไซต์: `app/layout.tsx`

## เทคโนโลยี

- React
- TypeScript
- Vinext / Vite
- CSS
